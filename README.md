---

## Rules to follow When Using Sphinx for Documentation

Use reStructuredText (.rst) format for all documentation pages

Maintain a clear title hierarchy using =, -, ~, ^ consistently for headings

Use a separate .rst file for each topic/module instead of long single pages

Always include a Table of Contents (toctree) in index.rst for navigation

Use meaningful page names and section names

Ensure internal page linking using :ref: instead of plain URLs

Insert images using:

.. image:: images/sample.png
    :align: center
    :scale: 60%


Maintain consistent formatting rules (fonts, bullet style, indentation)

Add short descriptions under headings, avoid long paragraphs

Use code blocks with:

.. code-block:: python


for command and script examples

Keep screenshots optimized, maintain uniform size and file naming

Build and verify HTML frequently to check for warnings or broken references

Maintain documentation version history through Git version control

Follow a review-before-publish cycle to ensure correctness and clarity
